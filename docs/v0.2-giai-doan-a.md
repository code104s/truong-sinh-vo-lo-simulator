## 1. Mục tiêu v0.2 (GDD 5)
"Bản đồ + hành động cơ bản + ô thời gian. Người chơi di chuyển, làm việc, tốn thời gian thật."

Cụ thể: từ 12 tuổi, mỗi tháng người chơi xếp 3 ô hành động (làm ruộng, làm thuê, săn, học chữ, luyện võ, nghỉ ngơi, đi thầy thuốc, đi tới quận khác). Mỗi hành động tốn thể lực/sức khỏe/rủi ro và đổi lại kỹ năng, hồi phục hoặc vị trí. Chạy được không giao diện với chiến lược tự động.

## 2. Hiện trạng liên quan
- Vòng tick có sẵn chỗ cho pha "Người chơi" (trống). Lịch, tua, lưu/tải, digest đều dùng lại được.
- `RegionLogic` đã có đồ thị kề quận và khoảng cách trị sở (km, số nguyên).
- **Lỗi mới phát hiện (đo trên 30 seed):** 20/30 vùng chơi **không liên thông** — 1–3 quận (có làng nơi sinh) không đi tới được từ kinh đô. Nguyên nhân và cách sửa ở ADR 0009. Phải sửa trước khi có di chuyển.
- Khoảng cách: quận kề nhau 54–117 km (2–4 ngày đi bộ ⇒ 1 ô); xuyên vùng 243–334 km (1–2 ô).
- Thuộc tính chưa có tác động: ngộ tính, tính cách, phúc duyên, linh căn.

## 4. Bản nháp bổ sung hợp đồng (`packages/shared`)
Viết bằng TypeScript; chốt ở Bước 0 sau khi duyệt, ghi vào nhật ký thay đổi của ADR 0001.
```ts
export type ActionId = string;                // vd. "action.farm"
export type CountyIndex = number;             // chỉ số quận trong RegionMapData.counties

export interface PlanSlot { action: ActionId; target?: CountyIndex }   // target khi di chuyển
export interface MonthPlan { slots: [PlanSlot, PlanSlot, PlanSlot] }

/** Hành động khả dụng ở nơi đang đứng, sim tính sẵn (FE không chứa luật). */
export interface ActionOption {
  id: ActionId;
  group: 'livelihood' | 'study' | 'rest' | 'heal' | 'travel';
  slots: number;                              // độ dài (ô)
  cost: { stamina: ContentId; risk: ContentId };   // mức chữ: "cost.low"…
  gains: ContentId[];                         // vd. "skill.farming"
  locked: ContentId | null;                   // lý do bị khóa, vd. "lock.winter"
}
export interface TravelOption { county: CountyIndex; slots: number; risk: ContentId }

// Bổ sung vào CharacterView
//   location: CountyIndex; home: CountyIndex;
//   staminaBand: 'fresh' | 'tired' | 'exhausted';
//   skills: { id: ContentId; rank: ContentId }[];
//   canAct: boolean;                          // false khi dưới 12 tuổi

// Bổ sung vào tin STATE
//   plan: MonthPlan | null; slotIndex: TenDay;
//   actions: ActionOption[]; travel: TravelOption[];

// Lệnh mới
//   { type: 'SET_PLAN'; reqId; plan: MonthPlan }
//   { type: 'PREVIEW_TRAVEL'; reqId; county: CountyIndex }   → tin TRAVEL_PREVIEW { route, slots, risk }

// Save version 2: thêm commandLog: CommandRecord[] (ADR 0011); RegionLogic thêm settlementKind theo quận.
```

## 6. Nghiệm thu v0.2 (đề xuất)
- `pnpm typecheck && pnpm test` xanh.
- 100 seed: đồ thị vùng liên thông, mọi nơi sinh tới được kinh đô; cùng seed cùng vùng.
- Tái lập: 10 seed × chiến lược ngẫu nhiên có seed, chạy 2 lần cùng digest; lưu giữa tháng → tải → chạy tiếp cùng digest; save xuất từ trình duyệt → `pnpm sim replay` cùng digest.
- Batch 1.000 đời × 5 chiến lược: 0 kẹt; tuổi thọ "lao lực" < "điều độ" < hoặc ≈ "lười"; mỗi chiến lược ≥ 85% chết trong 40–80 tuổi; báo cáo nguyên nhân chết theo chiến lược.
- Test: mọi hành động có giá; ngộ tính và thể chất có tác động đo được.
- FE: xếp kế hoạch, đi tới quận khác qua bản đồ, thấy giá trước khi chọn; ảnh từng màn ở 1280/1920.
