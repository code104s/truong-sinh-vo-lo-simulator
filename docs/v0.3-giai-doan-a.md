## 1. Mục tiêu v0.3 (GDD 5)
"Kinh tế phàm nhân + khung sự kiện. Đói, nghèo, bệnh gây hậu quả thật; ~30 sự kiện chạy được."

Cụ thể:
- **Lương thực và tiền:**
  - Người chơi phải có lương thực và tiền để sống.
  - Lương thực đến từ đất, lao động, chợ. Giá do mô phỏng chợ quận quyết định, theo mùa vụ và thiên tai.
  - Thiếu ăn thì đói, đói thì yếu, yếu thì chết.
- **Nghèo có hậu quả:** nghèo là không có tiền chữa bệnh, học, nộp thuế.
- **Sự kiện:** khoảng 30 sự kiện có điều kiện, có lựa chọn và lựa chọn nào cũng có giá.
- **Tất định và batch:**
  - Vẫn tất định, phát lại được.
  - Batch chứng minh lười biếng và nghèo khó có giá thật.

## 2. Hiện trạng liên quan (đo 2026-10-27)
- **Pha và tử vong:**
  - Vòng tick đã có pha Thế giới (trống) và pha Sự kiện (chỉ bệnh và tai nạn).
  - `DEATH_CAUSES` có sẵn `starvation` và `disaster`, nhưng chưa có đường dẫn tới.
- **Batch v0.2** (1.000 đời mỗi chiến lược), tuổi thọ trung bình:

  | Chiến lược | Tuổi thọ TB |
  |---|---|
  | lười | 61,64 |
  | điều độ | 61,41 |
  | lao lực | 57,22 |
  | học giả | 63,62 |
  | lang bạt | 59,72 |

  - "Lười" ≈ "điều độ": nghỉ ngơi không có giá. Đây là lỗ hổng lớn nhất v0.3 phải bịt.
  - Đi thầy thuốc gần như miễn phí.
- **Dữ liệu đất theo quận** (3 seed, 9–20 quận/vùng, 34 km²/ô):
  - Tỉ lệ đất canh tác theo quần xã: 85–100% ở mọi quận. Gần như không phân biệt được.
  - Độ cao trung bình quận: tsvl-01 dao động 0,11–0,74 km; tsvl-03 chỉ 0,01–0,15 km.
  - Nhiệt độ trung bình chênh ~3° trong một vùng.
  - `RegionMapData` chưa có lượng mưa.
  - ⇒ Độ phì nhiêu tính từ độ cao + sông + nhiệt độ (ADR 0012). Ở vùng đồng bằng, khác biệt giữa các quận chủ yếu đến từ thời tiết năm và thiên tai.
- **Tính cách:** 12 loại tính cách chưa có tác động nào (hoãn từ v0.2 Q7).
- **Kho chân dung NPC:** 100 ảnh, có chỉ mục giới/tuổi/tầng lớp, đã nhập nhưng chưa dùng. Dùng được cho thẻ sự kiện.
- **Nợ còn lại từ v0.2:**
  - Bộ nhớ đệm chống lệnh trùng (`handled`) của SimHost không giới hạn.
  - Nút "Xuất save" lộ cho người chơi.
  - Chưa chạy lại kiểm 100 seed vùng sau khi đổi ngưỡng sông.

## 4. Bản nháp bổ sung hợp đồng (`packages/shared`)
Chốt ở Bước 0 sau khi duyệt, ghi vào nhật ký thay đổi của ADR 0001.

```ts
// economy.ts
export type Coin = number;    // văn, số nguyên
export type Grain = number;   // thăng, số nguyên; 10 thăng = 1 đấu = khẩu phần người lớn một tuần
export const HUNGER_BANDS = ['fed', 'hungry', 'starving', 'famished'] as const;
export const SUPPLY_BANDS = ['plenty', 'normal', 'scarce', 'famine'] as const;
export const TENURES = ['none', 'tenant', 'owner', 'landlord'] as const;

export interface HouseholdView {
  independent: boolean;                    // đã lập thân chưa
  money: Coin;
  grain: Grain;
  landMu: number;
  tenure: (typeof TENURES)[number];
  hunger: (typeof HUNGER_BANDS)[number];   // dải, không lộ bộ đếm
  foodWeeksBand: 'none' | 'short' | 'season' | 'year';
}
export interface MarketView {
  county: CountyIndex;
  buyPrice: Coin;                          // văn/đấu khi mua
  sellPrice: Coin;                         // văn/đấu khi bán
  supply: (typeof SUPPLY_BANDS)[number];
  trend: 'falling' | 'steady' | 'rising';
  maxBuy: Grain; maxSell: Grain;           // giới hạn bởi kho/quỹ quận
}

// events.ts
export type EventCostTag = 'money' | 'grain' | 'health' | 'stamina' | 'time' | 'risk' | 'opportunity';
export interface EventChoiceView { id: string; costs: EventCostTag[]; locked: string | null }
export interface PendingEvent {
  instance: number;                        // tăng dần trong đời
  eventId: string;                         // "event.harvest_bad"
  variant: string | null;
  params: Record<string, string | number>;
  choices: EventChoiceView[];
  figure: { gender: Gender; ageBand: 'child' | 'young' | 'adult' | 'old'; class: 'poor' | 'common' | 'rich' | 'official' } | null; // gợi ý chân dung cho FE
}

// character.ts: CharacterView thêm household: HouseholdView
// HIDDEN_CHARACTER_KEYS thêm 'hunger', 'stayUntil'
// actions.ts: ActionOption.cost thêm money?: ContentId (cost.money.low|medium|high); thêm 'action.trade' (buôn bán nhỏ), lock 'lock.money', 'lock.no_work', 'lock.hunger'
// Skill thêm 'trade'

// protocol.ts — PROTOCOL_VERSION = 3
// Command thêm:
//   { type: 'TRADE'; reqId; grain: number }              // >0 mua, <0 bán (thăng), tại quận đang đứng
//   { type: 'CHOOSE'; reqId; instance: number; choice: string }
// STATE thêm: market: MarketView | null; pending: PendingEvent | null
// Kết quả ADVANCE thêm trạng thái 'event'; ADVANCE khi đang chờ → ERROR 'event.pending'

// save.ts — SAVE_VERSION = 3. Save v2 bị từ chối kèm thông báo rõ (Q9).
// worldgen RegionLogic — thêm fertilityPct: number[] (70..130)
```

- **Luồng RNG mới:** `economy`, `events`, `weather`. Mọi digest đời đổi; pin được cập nhật có chủ đích.
- **Nhật ký lệnh** ghi thêm `TRADE` và `CHOOSE` (ADR 0011).

## 6. Nghiệm thu v0.3 (đề xuất)
- `pnpm typecheck && pnpm test` xanh.
- **Bảo toàn và ổn định:**
  - sổ cái tiền không đổi ở mọi tick;
  - 100 năm không người chơi × 10 seed: không kho âm, giá trong [70%, 500%] giá gốc, mỗi quận đói kém khoảng 1 lần mỗi 8–15 năm.
- **Tái lập:**
  - 10 seed × chiến lược có seed (gồm `TRADE` và `CHOOSE`), chạy 2 lần cùng digest;
  - lưu khi đang có sự kiện chờ → tải → cùng digest;
  - save trình duyệt → replay cùng digest.
- **Batch 1.000 đời × chiến lược (Q3):**
  - 0 kẹt.
  - **lười:** tuổi thọ trung bình thấp hơn "điều độ" ít nhất 10 năm; ≥ 40% chết vì `starvation`.
  - **điều độ:** ≥ 80% chết trong 40–80 tuổi; `starvation` ≤ 5%.
  - **lao lực:** vẫn thấp hơn "điều độ".
  - **Xuất thân:** tuổi thọ trung bình `destitute` < `wealthy` ít nhất 5 năm ở cùng chiến lược.
  - **Sự kiện:** mỗi sự kiện xảy ra ≥ 1 lần (trừ sự kiện hiếm có ghi chú); trung bình 2–4 sự kiện có lựa chọn mỗi năm sau 12 tuổi (hạ từ 4–8 sau S6; nâng lại khi có thêm sự kiện).
- **FE:** thấy đói tới trước khi chết; mua bán được; chọn sự kiện được; ảnh từng màn.
